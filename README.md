
# 🚀 FormCraft – Drag & Drop Form Builder

Create beautiful and professional forms without writing a single line of code!

**FormCraft** is a simple and powerful form builder that allows users to design their own forms using an easy drag-and-drop interface, just like Google Forms.

## ✨ Features

- 🖱️ **Drag & Drop Builder** – Easily add and arrange form elements.
- 📝 **Multiple Form Elements** – Create forms using different input fields.
- 🎨 **Custom UI Design** – Customize the appearance of your forms.
- 👀 **Live Preview** – Preview your form while building it.
- ⚡ **Easy to Use** – No coding knowledge required.
- 📱 **Responsive Design** – Works on mobile, tablet, and desktop.
- 💾 **Save Forms** – Save your created forms (depending on supported storage).
- 🧩 **Flexible Layout** – Build forms according to your needs.

## 🎯 What Can You Create?

- Contact Forms
- Student Registration Forms

- Surveys
- Online Applications
- Quiz Forms
- Personal Forms

- HTML5
- CSS3

## 🚀 Getting Started

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start creating your own forms!
